# Changelog

## [1.0.0] - 2026-08-27

### Added
- Initial release
- Full REST API v1/v2 support
- GraphQL support
- OAuth2 authentication with refresh token
- Rate limiting (5 rps / 90 rpm)
- 60+ data models
- All endpoints: Anime, Manga, Ranobe, Users, UserRates, Topics, Comments, Characters, People, Reviews, Genres, Studios, Calendar, Abuse, Friends, Favorites, Bans, Forums, Achievements, EpisodeNotifications, GraphQL, Appears
- Java 11+ compatibility
- Maven and Gradle publishing support
- Fat JAR build
- Documentation and examples
